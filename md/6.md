### STEP 3: Optimize Dockerfile (Multi-Stage Build)

**Task:**
1. Create optimized `Dockerfile`:
   ```dockerfile
   # Stage 1: Restore dependencies (cached)
   FROM mcr.microsoft.com/dotnet/sdk:8.0-alpine AS restore
   
   WORKDIR /src
   
   # Copy ONLY .csproj files (minimal change = cache preserved)
   COPY ["src/AegisCore.API/AegisCore.API.csproj", "src/AegisCore.API/"]
   COPY ["src/AegisCore.Core/AegisCore.Core.csproj", "src/AegisCore.Core/"]
   COPY ["src/AegisCore.Data/AegisCore.Data.csproj", "src/AegisCore.Data/"]
   COPY ["AegisCore.sln", "./"]
   
   # Restore (cached until .csproj changes)
   RUN dotnet restore "AegisCore.sln"
   
   
   # Stage 2: Build
   FROM restore AS build
   
   WORKDIR /src
   
   # Copy ALL source code
   COPY . .
   
   # Build
   RUN dotnet build "src/AegisCore.API/AegisCore.API.csproj" -c Release -o /app/build \
       --no-restore
   
   
   # Stage 3: Publish (slim down)
   FROM build AS publish
   
   RUN dotnet publish "src/AegisCore.API/AegisCore.API.csproj" \
       -c Release -o /app/publish \
       --no-build \
       --no-self-contained \
       -p:PublishSingleFile=false \
       -p:PublishTrimmed=false \
       -p:PublishReadyToRun=true
   
   
   # Stage 4: Runtime (minimal)
   FROM mcr.microsoft.com/dotnet/aspnet:8.0-alpine
   
   # Install curl for health checks
   RUN apk add --no-cache curl
   
   WORKDIR /app
   
   # Copy published files
   COPY --from=publish /app/publish .
   
   # Create non-root user for security
   RUN addgroup -S aegiscore && adduser -S aegiscore -G aegiscore
   USER aegiscore
   
   # Environment variables
   ENV ASPNETCORE_URLS=http://+:5000
   ENV ASPNETCORE_ENVIRONMENT=Production
   
   # Health check (Docker knows if container is healthy)
   HEALTHCHECK --interval=30s --timeout=3s --start-period=40s --retries=3 \
       CMD curl -f http://localhost:5000/health || exit 1
   
   EXPOSE 5000
   
   # Run application
   ENTRYPOINT ["dotnet", "AegisCore.API.dll"]
   ```

2. Benefits of this Dockerfile:
   ```
   ✅ Restore stage cached (independent of source code)
   ✅ Build stage reuses restore cache
   ✅ Publish stage optimized (PublishReadyToRun)
   ✅ Runtime stage minimal (alpine base = 150MB)
   ✅ Non-root user (security hardening)
   ✅ Health check (Docker-aware monitoring)
   ```

3. Output: Optimized multi-stage Dockerfile

**Expected Results:**

- Build time: 2-3 min (down from 8-10 min)

**Checklist:**

   ```csharp
   // Before: Synchronous startup
   public void ConfigureServices(IServiceCollection services)
   {
       // This blocks startup
       _rbacService.LoadAllPolicies(); // Takes 2 seconds
       _cacheService.WarmUp(); // Takes 1 second
   }
   
   // After: Async/lazy loading
   public void ConfigureServices(IServiceCollection services)
   {
       // Lazy load, don't block startup
       services.AddSingleton<IRBACService>(sp => 
           new RBACService(lazy: true)); // Loads on first use
       
       // Warm up cache in background
       Task.Run(() => _cacheService.WarmUp());
   }
   ```

### STEP 7: Auto-Launch Browser on Successful Startup

**Task:**

**Option A: Docker Compose with Script**
1. Create `docker-compose.yml`:
   ```yaml
   version: '3.8'
   
   services:
     api:
       build:
         context: .
         dockerfile: Dockerfile
       ports:
         - "5000:5000"
       environment:
         - ASPNETCORE_ENVIRONMENT=Development
       healthcheck:
         test: ["CMD", "curl", "-f", "http://localhost:5000/health"]
         interval: 5s
         timeout: 3s
         retries: 3
         start_period: 10s
   
   volumes:
     - postgres-data:/var/lib/postgresql/data
   ```

2. Create `scripts/start-and-open.sh`:
   ```bash
   #!/bin/bash
   
   echo "🚀 Starting AegisCore Docker container..."
   docker-compose up -d
   
   # Wait for health check to pass
   echo "⏳ Waiting for application to be ready..."
   timeout 60 bash -c '
   until docker-compose exec -T api curl -f http://localhost:5000/health > /dev/null 2>&1; do
       echo -n "."
       sleep 1
   done
   '
   
   if [ $? -eq 0 ]; then
       echo "✅ Application is ready!"
       sleep 1
       
       # Open browser
       case "$OSTYPE" in
           darwin*) open http://localhost:5000 ;;
           linux*) xdg-open http://localhost:5000 || echo "Open http://localhost:5000 in your browser" ;;
           msys*) start http://localhost:5000 ;;
       esac
   else
       echo "❌ Application failed to start"
       exit 1
   fi
   ```

3. Make executable:
   ```bash
   chmod +x scripts/start-and-open.sh
   ```
