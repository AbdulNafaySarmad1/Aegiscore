# PROMPT 4: Interactive Instruction Manual Generator
## Create Beautiful, Beginner-Friendly Installation & Setup Guides

---

## OBJECTIVE

Generate interactive HTML installation manuals that:
1. Use **simple, everyday language** (no jargon)
2. Include **step-by-step guidance** (like a parent guiding a child)
3. Have **visual indicators** (checkmarks, progress bars)
4. Provide **multiple paths** (Windows, macOS, Linux)
5. Include **troubleshooting sections** (common errors + fixes)
6. Are **mobile-responsive** (works on phone + tablet + desktop)

---

## OUTPUT FORMAT

For EACH of these topics, generate an interactive HTML manual:

1. **Installation Guide** — How to install AegisCore backend locally
2. **Frontend Setup** — How to install React frontend locally
3. **Mobile Setup** — How to set up mobile apps (Expo, Android, iOS)
4. **Docker Deployment** — How to deploy using Docker
5. **Kubernetes Deployment** — How to deploy on Kubernetes (Azure or on-prem)
6. **Database Setup** — How to set up PostgreSQL + Redis
7. **Troubleshooting Guide** — Common problems + solutions
8. **Contributing Guide** — How to contribute code to the project

## LANGUAGE PRINCIPLES

**Use simple, everyday language:**

❌ **Bad (too technical):**
```
"Configure the PostgreSQL connection string in the appsettings.json 
file using the following connection pool parameters..."
```

✅ **Good (beginner-friendly):**
```
"Tell AegisCore how to find your database.
Think of it like giving a friend your home address.
Open the file called appsettings.json and replace the database address 
with your PostgreSQL server's address."
```

---

## TONE & ANALOGY

**Use everyday analogies:**

- **Installation** = "Like installing an app on your phone"
- **Port** = "Like a door number on a building"
- **Database** = "Like a filing cabinet that stores everything"
- **API** = "Like a waiter taking your order to the kitchen"
- **Docker** = "Like a box that contains everything your app needs"
- **Git** = "Like saving versions of your homework, not just the final copy"

---

## FORMATTING GUIDELINES

**✅ DO:**
- Use checkmarks (✅) for success states
- Use warnings (⚠️) for potential issues
- Use emoji for visual interest (🚀 Starting, 🐳 Docker, 💾 Database)
- Break into small steps (never > 5 lines per step)
- Include pictures/screenshots (if possible)
- Use `code` formatting for commands
- Have expandable sections (details/summary)
- Provide multiple paths (Windows/macOS/Linux)

**❌ DON'T:**
- Use technical jargon without explaining
- Write paragraphs longer than 3 lines
- Assume prior knowledge
- Mix multiple concepts in one step
- Use complex diagrams
