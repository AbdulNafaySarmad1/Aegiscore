## 📝 PROMPT 1: Frontend/Backend Split

**What it does:**
- Separates monolithic code into clean architecture
- Creates 3 independent repositories:
  - `aegiscore-backend/` — C# .NET 10 API only
  - `aegiscore-frontend/` — React web app only
  - `aegiscore-mobile/` — React Native + Kotlin + Swift

**Why:**
- Independent deployments (deploy backend without frontend)
- Independent versioning (backend v1.5, frontend v2.0)
- Faster CI/CD (only rebuild what changed)
- Team scalability (frontend team, backend team, mobile team)

**Example Output:**
```
aegiscore-backend/
├─ src/AegisCore.API/
├─ Dockerfile (backend only)
└─ k8s/manifests/

aegiscore-frontend/
├─ src/components/
├─ package.json
└─ Dockerfile (Node.js)

aegiscore-mobile/
├─ react-native/
├─ android/ (Kotlin)
└─ ios/ (Swift)
```

**When to use:** After Prompt 5 (testing complete)
