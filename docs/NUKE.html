Rule #1: never delete the Postgres volume during a demo unless you explicitly intend to reseed the entire universe.

1. The only startup sequence you should need

cd ~/Music/Aegiscore/Aegiscore-demo-integration git switch agent/prod-hardening git pull origin agent/prod-hardening docker compose \ --env-file .env \ -f docker-compose.yml \ -f docker-compose.cloud.yml \ -f docker-compose.local-demo.yml \ build api portal docker compose \ --env-file .env \ -f docker-compose.yml \ -f docker-compose.cloud.yml \ -f docker-compose.local-demo.yml \ up -d --force-recreate postgres redis api portal
docker compose \ --env-file .env \ -f docker-compose.yml \ -f docker-compose.cloud.yml \ -f docker-compose.local-demo.yml \ ps
Expected: Postgres healthy, Redis healthy, API healthy, Portal healthy/starting then healthy. Do not continue if API is unhealthy.

3. Health in 30 seconds

curl -fsS http://127.0.0.1:8080/health || true curl -fsS http://127.0.0.1:8080/api/portal-health || true
docker compose \ --env-file .env \ -f docker-compose.yml \ -f docker-compose.cloud.yml \ -f docker-compose.local-demo.yml \ logs --since=5m api portal 2>&1 | grep -Ei 'FTL|Unhandled|Exception|error|status.?500' || true

No fatal/Unhandled/500 output is what you want. Warnings are not automatically demo blockers.

6. If the UI says 404

1
Confirm the source file exists on agent/prod-hardening.
2
Rebuild the service that owns the route. API route → rebuild API. Next.js page → rebuild portal.
3
Do not assume browser cache if the API itself returns 404.
docker compose --env-file .env -f docker-compose.yml -f docker-compose.cloud.yml -f docker-compose.local-demo.yml build --no-cache api portal

7. If login suddenly fails

First verify which account is actually in Postgres. Do not delete the database.

docker compose --env-file .env -f docker-compose.yml -f docker-compose.cloud.yml -f docker-compose.local-demo.yml exec postgres psql -U aegiscore -d aegiscore -c 'SELECT "Id","Email","FirstName","LastName" FROM "Users" ORDER BY "Email";'

If the account exists, the seeder will skip it. Fix only that account/password rather than resetting everything.

8. The dangerous button you should almost never press

THIS DESTROYS LOCAL DEMO DATA. Only use it when you explicitly want a completely clean reseed and you have enough time to rebuild/retest.
docker compose --env-file .env -f docker-compose.yml -f docker-compose.cloud.yml -f docker-compose.local-demo.yml down docker volume rm aegiscore_aegiscore_demo_postgres

9. Final “stop touching it” checklist

When every box is checked: tag the commit, close the laptop, and demo the product. No “one tiny improvement” five minutes before the meeting.
