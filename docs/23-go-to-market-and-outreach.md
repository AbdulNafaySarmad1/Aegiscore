# Go-To-Market and Outreach

## Strategy

1. Sell a 90-day pilot around admissions, examination governance, and OBE.
2. Use on-prem deployment as the trust opener for public universities.
3. Use cloud deployment speed for private universities.
4. Convert pilot into campus-wide rollout by adding finance, HR/payroll, portals, and mobile.
5. Launch plugin marketplace after the first three production campuses.
