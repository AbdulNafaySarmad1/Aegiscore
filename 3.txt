═══════════════════════════════════════════════════════════════
WHAT COUNTS AS HARDCODING (treat all of these as bugs)
═══════════════════════════════════════════════════════════════

STRINGS & COPY
  ✗ Any English string rendered directly in JSX or returned from an API
  ✗ Any label, placeholder, tooltip, button text, error message, or toast 
    that is not sourced from t() or an i18n key
  ✗ Any currency symbol, currency code, or number format that is not 
    pulled from tenant config
  ✗ Any date format, fiscal year start/end, or calendar type not pulled 
    from tenant or user locale config
  ✗ Any university name, department name, or role label baked into code

NUMBERS & THRESHOLDS
  ✗ Any PKR amount, percentage threshold, or limit written as a literal
  ✗ Any pagination page size that is not from config
  ✗ Any timeout, retry count, or debounce delay that is not from a 
    constants file or environment variable
  ✗ Any chart height, breakpoint, or grid size not from the design token system
  ✗ Any sigma threshold for anomaly detection (currently hardcoded as 2σ — 
    must come from tenant analytics config)

COLORS & THEMING
  ✗ Any hex code, rgb(), hsl(), or named colour not from the AegisCore token system
  ✗ Any inline style with a colour value
  ✗ Any Tailwind arbitrary colour value e.g. bg-[#1a2b3c]
  ✗ Any chart series colour not from the token palette

ROUTING & PERMISSIONS
  ✗ Any route string written as a literal anywhere outside the central 
    route registry
  ✗ Any role name ('CFO', 'Registrar', 'Student') written as a string 
    literal in a conditional — use role enums from the auth config
  ✗ Any permission check that is not driven by the RBAC policy engine
  ✗ Any feature flag checked as a boolean literal — use the feature flag store

ENVIRONMENT & INFRASTRUCTURE
  ✗ Any IP address, hostname, port, or URL written in application code
  ✗ Any database connection string, credential, or secret outside .env
  ✗ Any S3 bucket name, region, or ARN in application code
  ✗ Any API key, token, or secret in any file that is not .env or a 
    secrets manager reference
  ✗ Any cloud provider name baked into logic (must be provider-agnostic)
  ✗ Any file path separator assumed to be / or \ — use path.join()

DATABASE & SCHEMA
  ✗ Any table name or column name written as a raw string outside the 
    ORM model definitions
  ✗ Any enum value written as a string literal in queries — use the 
    defined enum types
  ✗ Any default value baked into application code that should live in 
    the database schema or migration

CHARTS & VISUALISATION
  ✗ Any insight chip text that is a hardcoded string — must be computed 
    from live data at render time
  ✗ Any axis label that is not pulled from the data schema or i18n key
  ✗ Any legend label written as a string literal
  ✗ Any date range default that is not from the tenant fiscal year config
  ✗ Any chart colour series that is not from the token system

PERSONALITY MODE
  ✗ Any personality copy written inline — must be an i18n key with 
    .personality variant
  ✗ Any hardcoded list of "which roles get personality mode ON by default" — 
    must come from tenant config object
  ✗ Any emoji written as a literal character in JSX — must be in the 
    i18n value, never in the component

═══════════════════════════════════════════════════════════════
WHAT TO REPLACE EACH WITH
═══════════════════════════════════════════════════════════════

HARDCODED STRING       → t('module.context.element.state') i18n key
HARDCODED COLOUR       → var(--aegiscore-[token-name]) CSS variable
HARDCODED NUMBER       → env variable OR tenant config field OR design token
HARDCODED ROLE STRING  → RoleEnum.CFO / RoleEnum.Student etc. from auth types
HARDCODED ROUTE        → ROUTES.finance.gl.entry or equivalent from route registry
HARDCODED FEATURE FLAG → featureFlags.get('feature-name') from flag store
HARDCODED THRESHOLD    → tenantConfig.analytics.anomalyThresholdSigma
HARDCODED FISCAL YEAR  → tenantConfig.fiscalYear.startMonth / endMonth
HARDCODED CURRENCY     → tenantConfig.currency.code / tenantConfig.currency.format
HARDCODED DATE FORMAT  → Intl.DateTimeFormat with userLocale from session
HARDCODED CHART SIZE   → token('chart.height.mobile') etc. from token system
HARDCODED API URL      → process.env.API_BASE_URL or service discovery

═══════════════════════════════════════════════════════════════
DYNAMIC SYSTEMS THAT MUST EXIST (create if missing)
═══════════════════════════════════════════════════════════════

① TENANT CONFIG OBJECT (loaded at boot, cached in Zustand)
  Shape:
  {
    id: string,
    name: string,                          // never hardcoded anywhere
    type: 'public' | 'private' | 'govt',
    currency: {
      code: string,                        // 'PKR' | 'USD' | etc.
      format: 'south-asian' | 'western',
      symbol: string
    },
    fiscalYear: {
      startMonth: number,                  // 1–12, default 7 (July)
      endMonth: number                     // 1–12, default 6 (June)
    },
    locale: {
      default: string,                     // 'en-PK' | 'ur-PK' | 'ar'
      available: string[]
    },
    calendar: 'gregorian' | 'hijri',
    personalityMode: {
      enabled: boolean,
      lockedOff: boolean,
      defaultByRole: Record<RoleEnum, boolean>
    },
    analytics: {
      anomalyThresholdSigma: number,       // default 2
      insightChipEnabled: boolean
    },
    branding: {
      primaryColor: string,               // injected as CSS variable at runtime
      logoUrl: string,
      portalName: string
    },
    features: Record<string, boolean>     // feature flags
  }

② ROUTE REGISTRY (single source of truth for all routes)
  All routes defined once, exported as typed constants.
  Zero route strings written anywhere else in the codebase.

③ ROLE ENUM (single source of truth for all role identifiers)
  Never compare against 'CFO' or 'student' string literals.
  Always use RoleEnum.CFO, RoleEnum.Student etc.

④ DESIGN TOKEN SYSTEM (all visual values)
  All spacing, colour, typography, chart sizing from CSS custom properties.
  Zero px values in JS. Zero hex codes in components.

⑤ i18n KEY REGISTRY (all user-visible strings)
  Every string that a user sees is a key.
  Keys follow: t('module.context.element.state[.personality]')
  Missing keys fall back silently — never show a raw key to a user.

⑥ FEATURE FLAG STORE
  All feature availability checked via featureFlags.isEnabled('flag-name').
  Flags are tenant-scoped and loaded from the tenant config at boot.
