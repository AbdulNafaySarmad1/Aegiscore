Nocturne Contributing Guide

Make changes without breaking the build.

1Create a branch

git checkout -b feature/short-name

2Run checks

dotnet test Nocturne.slnx -m:1 -p:BuildInParallel=false
cd Nocturne.Portal && npm run build
cd ../Nocturne.Mobile && npm run typecheck

3Open a PR

Describe the behavior change, tests run, and any deployment notes.

4Secrets rule

Never commit `.env`, signing keys, API tokens, database dumps, or generated app bundles.
