AegisCore Kubernetes Deployment

Deploy to AKS or on-prem Kubernetes.

1Prerequisites

You need `kubectl`, registry access, and production secrets.

kubectl version --client

2Build image

docker build -t registry.example/aegiscore-api:1.0.0 .
docker push registry.example/aegiscore-api:1.0.0

3Apply manifests

kubectl apply -f k8s/
kubectl rollout status deploy/aegiscore-api

?Troubleshooting

Pods crash

Run `kubectl logs deploy/aegiscore-api` and check missing secrets or database connectivity.
