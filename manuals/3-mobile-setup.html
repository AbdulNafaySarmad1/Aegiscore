AegisCore Mobile Setup

Set up Expo, Android, and iOS mobile apps.

1Expo app

cd aegiscore-mobile/react-native
npm install
cp ../.env.example .env
npm run typecheck
npm test

2Android native

Open `aegiscore-mobile/android` in Android Studio.

export AEGISCORE_API_BASE_URL=http://localhost:8080
./gradlew build

3iOS native

Open `aegiscore-mobile/ios` in Xcode on macOS, set the API URL in scheme environment variables, then build.

?Troubleshooting

iOS build unavailable

You need macOS and Xcode. Linux workspaces can inspect source but cannot produce an IPA.
