AegisCore Database Setup

PostgreSQL plus Redis for local development.

1Start services

docker compose --env-file .env.example up -d postgres redis

2Apply migrations

dotnet tool restore
dotnet tool run dotnet-ef database update --project AegisCore.Infrastructure/AegisCore.Infrastructure.csproj --startup-project AegisCore.API/AegisCore.API.csproj --context AegisDbContext

3Check

docker compose --env-file .env.example exec -T postgres psql -U aegiscore -d aegiscore -c "select count(*) from \"__EFMigrationsHistory\";"
