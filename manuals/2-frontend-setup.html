AegisCore Frontend Setup

Run the React portal separately from the backend.

1Install tools

Install Node.js 20 and npm.

node --version
npm --version

2Configure API URL

cd aegiscore-frontend
cp .env.example .env.local
# edit VITE_API_URL if your backend is not on localhost:8080

3Start

npm install
npm run dev

Open the Vite URL shown in the terminal.

4Build check

npm run build

?Troubleshooting

API calls fail

Check `VITE_API_URL` and make sure the backend CORS allowed origin includes your frontend URL.
