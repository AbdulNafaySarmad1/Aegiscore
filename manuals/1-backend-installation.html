Nocturne Backend Installation

Install and run the .NET API on your computer.

1What you need

Install .NET 10 SDK, Docker Desktop, and Git.


dotnet --version
docker --version
git --version

2Install

winget install Microsoft.DotNet.SDK.10
winget install Docker.DockerDesktop
brew install dotnet docker
open -a Docker
sudo apt-get update
sudo apt-get install -y dotnet-sdk-10.0 docker.io

3Run

cp .env.example .env
dotnet test Nocturne.slnx
docker compose --env-file .env up -d --build
curl http://localhost:8080/health

4Success

Open http://localhost:8080. The API should answer health checks.

?Troubleshooting

Port already in use

Stop the other app or change the published port in `docker-compose.yml`.

Docker cannot connect

Open Docker Desktop and wait until it says Docker is running.
