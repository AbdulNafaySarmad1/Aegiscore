AegisCore Troubleshooting

Common problems and direct fixes.

1Health check fails

docker compose --env-file .env.example ps
docker compose --env-file .env.example logs api --tail=200

2Database connection fails

Check `AEGISCORE_DB_CONNECTION` and Postgres credentials.

3License lockout

`/api/license/status` explains the current state. Activate or override with a SuperAdmin token.

4CORS error

Add the frontend URL to `Cors:AllowedOrigins` or `AllowedOrigins` in the backend configuration.
