# PROMPT 3: Git Repository Cleanup & Tree Optimization
## Prune Dead Branches, Clean History, Optimize Repository

---

## OBJECTIVE

1. Remove dead/stale branches
2. Clean up large files from history
3. Optimize repository size
4. Remove secrets accidentally committed
5. Consolidate messy commit history
6. Prepare for split repositories (backend/frontend/mobile)

---

## EXECUTION STEPS

### STEP 1: Audit Git Repository Size & Branches

**Task:**
1. Check total repo size:
   ```bash
   du -sh .git
   ```

2. List all branches (local + remote):
   ```bash
   git branch -a
   git branch -v (show last commit on each)
   ```

3. Identify dead branches:
   - Branches not merged to main (likely experimental)
   - Branches older than 6 months
   - Branches with outdated names (e.g., `old-feature`, `legacy-*`)

4. Output: Report of branches to delete

**Example:**
```
DEAD BRANCHES TO DELETE:
- feature/old-login (last commit: 8 months ago)
- bugfix/incomplete-payments (merged, but branch still exists)
- exp/experiment-123 (experimental, incomplete)
- release/v0.5 (old release, no longer relevant)
```

**Checklist:**
- [ ] Identified all dead branches
- [ ] Confirmed branches are not checked out
- [ ] Backed up any important branches

---

### STEP 2: Delete Dead/Stale Branches

**Task:**
1. Delete local dead branches:
   ```bash
   git branch -d feature/old-login
   git branch -d bugfix/incomplete-payments
   git branch -d exp/experiment-123
   git branch -D release/v0.5 # Force delete if not merged
   ```

2. Delete remote dead branches:
   ```bash
   git push origin --delete feature/old-login
   git push origin --delete bugfix/incomplete-payments
   git push origin --delete exp/experiment-123
   git push origin --delete release/v0.5
   ```

3. Prune remote branches locally:
   ```bash
   git fetch --prune
   git branch -r --merged | grep -v main | xargs git branch -r -d
   ```

4. Output: Only relevant branches remain

**Checklist:**
- [ ] All dead branches deleted locally
- [ ] All dead branches deleted from remote
- [ ] Remote pruned: `git fetch --prune`
- [ ] Only main, develop, release branches remain

### STEP 3: Detect & Remove Large Files in History

**Task:**
1. Find large files in git history:
   ```bash
   git rev-list --all --objects | sed -n $(git rev-list --objects --all | cut -f1 -d' ' | \
     git cat-file --batch-check | grep blob | sort -t' ' -k3 -n | tail -10 | \
     while read hash type size; do echo -n "-e s/$hash/$size/p "; done) | sort -t' ' -k2 -n | tail -10
   ```

2. Or use `bfg` tool (simpler):
   ```bash
   # Install: brew install bfg (macOS) or apt-get install bfg (Linux)
   
   # Find files > 10MB
   bfg --strip-blobs-bigger-than 10M --no-blob-protection
   ```

3. Identify files to remove:
   - Large binaries (`.exe`, `.dmg`, `.iso`)
   - Node_modules or build artifacts committed accidentally
   - Large database dumps
   - Large media files (videos, archives)

4. Output: List of files to remove

**Example:**
```
LARGE FILES TO REMOVE:
- node_modules.zip (847 MB) - Should be .gitignored
- database-backup.sql (450 MB) - Should be .gitignored
- old-build.tar.gz (234 MB) - Build artifact, not source
- legacy-video.mp4 (156 MB) - Media should be on S3
```

**Checklist:**
- [ ] Identified all files > 10MB
- [ ] Confirmed files should not be in git
- [ ] Have backups if necessary

---

### STEP 4: Remove Large Files from Git History

**Task:**
1. Use `bfg` to remove large files:
   ```bash
   # Clone a mirror (preserves all history)
   git clone --mirror https://github.com/AbdulNafaySarmad/nocturne.git nocturne.git.bak
   cd nocturne.git.bak
   
   # Remove files > 10MB
   bfg --strip-blobs-bigger-than 10M
   
   # Apply changes
   git reflog expire --expire=now --all
   git gc --prune=now --aggressive
   ```

2. Force push cleaned history:
   ```bash
   cd ../nocturne
   git fetch --mirror
   git push --force --all
   git push --force --tags
   ```

3. Verify large files are removed:
   ```bash
   git rev-list --all --objects | sort -k2 | tail -20
   ```

4. Output: Cleaned git history

**Checklist:**
- [ ] Large files removed from history
- [ ] All commits still intact (no data loss)
- [ ] Repository size reduced significantly

### STEP 5: Detect & Remove Secrets

**Task:**
1. Scan for accidentally committed secrets:
   ```bash
   # Install: brew install detect-secrets (macOS) or pip install detect-secrets (Linux)
   
   detect-secrets scan > .secrets.baseline
   detect-secrets audit .secrets.baseline
   ```

2. Look for patterns:
   ```bash
   git log -p | grep -i "password\|api_key\|secret\|token" | head -20
   ```

3. Common secrets to check:
   - AWS keys (AKIA...)
   - Azure keys (DefaultEndpointsProtocol=...)
   - Database passwords (connstr=...)
   - JWT tokens
   - API keys

4. Identify commits with secrets:
   ```
   COMMITS WITH SECRETS:
   - abc1234: Added appsettings.json with DB password
   - def5678: Committed .env file with API keys
   - ghi9012: Hard-coded Azure connection string
   ```

5. Output: List of commits to rewrite

**Checklist:**
- [ ] Scanned for secrets
- [ ] Identified all commits with secrets
- [ ] Backed up any important values before removal

---

### STEP 6: Remove Secrets from Git History

**Task:**
1. Use `bfg` to remove secrets:
   ```bash
   # Create a file list of patterns to remove
   echo "PASSWORD" > secrets.txt
   echo "api_key" >> secrets.txt
   echo "connection.*string" >> secrets.txt
   
   # Remove from history
   bfg --replace-text secrets.txt
   
   # Apply
   git reflog expire --expire=now --all
   git gc --prune=now --aggressive
   ```

2. Rewrite commits with inline secrets:
   ```bash
   git filter-branch --tree-filter 'find . -name "appsettings.json" -delete' HEAD
   git filter-branch --tree-filter 'find . -name ".env" -delete' HEAD
   ```

3. Force push cleaned history:
   ```bash
   git push --force --all
   git push --force --tags
   ```

4. **Notify team:** Anyone with local clones must:
   ```bash
   git fetch --prune
   git reset --hard origin/main
   ```

5. Output: Secrets removed from git history

**Checklist:**
- [ ] Secrets identified and logged (safe location)
- [ ] Secrets removed from git history
- [ ] Force pushed to remote
- [ ] Team notified to update local clones
- [ ] Actual secrets rotated in production (if exposed)

### STEP 7: Consolidate Messy Commit History

**Task:**
1. Review recent commit history:
   ```bash
   git log --oneline -20
   ```

2. Identify messy commits:
   - "WIP" commits (work in progress)
   - "Fix typo" commits
   - Multiple commits for single feature
   - Repeated fixes for same bug

3. Interactive rebase to clean up:
   ```bash
   git rebase -i HEAD~20 # Rebase last 20 commits
   ```

4. In interactive rebase editor:
   ```
   pick abc1234 Feature: User authentication
   squash def5678 Fix: User auth token validation  ← Combine with above
   squash ghi9012 WIP: Complete user auth         ← Combine with above
   pick jkl3456 Feature: Exam grading
   reword mno7890 Fix typo                        ← Rename to better message
   drop pqr1234 Experimental code                 ← Remove entirely
   ```

5. Force push cleaned history:
   ```bash
   git push --force origin main
   ```

6. Output: Clean, organized commit history

**Checklist:**
- [ ] Messy commits identified
- [ ] Interactive rebase completed
- [ ] Commits are logically organized (one feature = one commit)
- [ ] Commit messages are clear (not "WIP", "fix", etc.)
- [ ] History force-pushed to remote

### STEP 8: Update .gitignore

**Task:**
1. Create comprehensive `.gitignore`:
   ```
   # Build artifacts
   build/
   dist/
   bin/
   obj/
   *.o
   *.exe
   *.dll
   
   # Dependencies
   node_modules/
   packages/
   .gradle/

   .vscode/
   .idea/
   *.swp
   *.swo
   *~
   .DS_Store
   
   # Environment
   .env
   .env.local
   appsettings.Development.json
   
   # Secrets
   *.key
   *.pem
   *.pfx
   *.jks
   
   # Database
   *.db
   *.sqlite

   # Large files

   *.mp4
   *.avi
   *.mov
   ```

2. Apply `.gitignore`:
   ```bash
   git add .gitignore
   git commit -m "chore: Update .gitignore to prevent future commits"
   git push
   ```

3. Remove previously committed ignored files:
   ```bash
   git rm --cached .env
   git rm --cached appsettings.Development.json
   git commit -m "chore: Remove sensitive files from tracking"
   git push
   ```

4. Output: Clean `.gitignore` + repository

**Checklist:**
- [ ] `.gitignore` covers all build artifacts
- [ ] `.gitignore` covers all environment files
- [ ] `.gitignore` covers all secrets
- [ ] Previously ignored files removed from tracking
- [ ] Committed to repository
