================================================================================
AEGISCORE — COMPLETE FUNCTIONALITY REFERENCE
================================================================================

AegisCore is a quantum-safe institutional ERP for universities. It covers every
stakeholder from a first-year student paying challan to a Board of Governors
member reviewing endowment performance.

Technology: .NET 10 (C# 14) backend, Next.js 16 (React 19) frontend,
PostgreSQL 17 with pgvector, Redis 7, Docker multi-stage Alpine deployment.

================================================================================
ARCHITECTURE
================================================================================

Clean Architecture modular monolith with multi-tenant isolation:
  Domain Layer    — 188 entity classes, 170+ enums
  Application     — 60+ service interfaces, contracts, DTOs
  Infrastructure  — EF Core, migrations, repositories, external adapters
  API             — 62 controllers, SignalR hubs, minimal API endpoints
  Portal          — 27 page routes, 15 components, 5 i18n locales
  Tests           — 508 unit/integration tests

ACADEMIC-01 — GRADE APPEALS WORKFLOW
-----------------------------------------------------------------------
  Complete lifecycle: eligibility gate → grounds classification (Clerical
  Error, Rubric Misapplication, Missing Submission, Bias Claim, Policy
  Violation, Extenuating Circumstance) → evidence audit with strength
  scoring → faculty response template → committee brief generation →
  outcome processing (Upheld/Partially Upheld/Dismissed/Deferred).
  Frontend: submission form with file upload, appeals table with status
  badges, committee brief viewer, classify/decision actions.

ACADEMIC-02 — AUTO GRADE DISTRIBUTION ANALYSIS
-----------------------------------------------------------------------
  Statistical profiling per course: mean, median, mode, standard deviation,
  variance, skewness, kurtosis, pass/failure/distinction rates, percentile
  breakdown. Anomaly detection: high failure rate (>35%), grade inflation
  (>60% distinction), clustering anomaly (std dev <5), bimodal distribution,
  significant deviation from historical baseline, section-to-section variance.
  Frontend: course selector, stat cards, distribution bar chart, anomaly
  alerts table with severity color-coding.

ACADEMIC-03 — PLAGIARISM DETECTION ACROSS SEMESTERS
-----------------------------------------------------------------------
  Multi-layer scan: verbatim match, paraphrase detection (cosine similarity
  on sentence embeddings), structural fingerprinting (paragraph ordering,
  citation placement), cross-semester ghost-writing detection (Burrows'
  Delta style consistency), collusion ring detection via similarity graph
  clustering, AI-generated content probability (burstiness/perplexity).
  Tier classification: Tier 1 Administrative (<15%), Tier 2 Academic
  Misconduct (15-40%), Tier 3 Severe Misconduct (>40%), Tier 4 Collusion Ring.
  Frontend: text input with Scan, SVG gauge with color bands, 4 match-type
  tabs, matched sources list, collusion graph section.

COURSE CATALOG INGESTION ENGINE
-----------------------------------------------------------------------
  Document-to-database pipeline: accepts scanned PDF (CamScan, Adobe
  Scan), digital PDF, images (JPG/PNG/WEBP/HEIC), Excel/CSV, Word
  documents. Multi-stage: document reception → classification (MIME
  type + magic bytes + text density detection for scanned vs digital
  decision) → text extraction (digital: layout-preserving text; scanned:
  OCR with deskew/contrast enhancement, configurable provider: Google
  Vision/Azure/AWS Textract/Tesseract) → structure detection (degree
  program headers, semester grouping, table columns identified by content
  pattern not position, credit hour format detection "3+0"/"0+1"/"3+0/
  2+1", prerequisite chain detection, removed course detection via
  strikethrough/greyed text) → data normalization → validation (code
  pattern, credit limits, prerequisite graph: circular/orphan/forward
  detection, duplicate detection with update candidate flagging) →
  review queue (confidence-scored items needing human review, image crop
  alongside parsed data, approve/reject) → database insertion (transactional
  per degree program, idempotent import). Versioned catalogs with full
  history. Degree tree computation: DAG graph of prerequisite relationships,
  critical path identification for graduation bottlenecks.
