### STEP 1: Audit Kotlin Code for Dead Code

**Task:**
1. Scan `app/src/main/kotlin/` for:
   - Unused functions (never called)
   - Unused classes (never instantiated)
   - Unused variables (assigned but never read)
   - Unused imports (warning in IDE)
   - Dead code blocks (commented-out code)

2. For each file, identify:
   ```kotlin
   // DEAD: This function is never called anywhere
   fun oldLoginFlow() { ... } // DELETE
   
   // DEAD: This import is unused
   import android.provider.Settings // DELETE
   
   // DEAD: This variable is assigned but never read
   val unused = someValue // DELETE
   ```

3. Output: Report of all dead code locations

**Checklist:**
- [ ] List all unused functions (with line numbers)
- [ ] List all unused classes (with line numbers)
- [ ] List all unused variables (with line numbers)
- [ ] List all unused imports
- [ ] List all commented-out code blocks

### STEP 9: Set Up CI/CD for Android

**Task:**
1. Create `.github/workflows/android-build.yml`:
   ```yaml
   name: Android Build & Test
   
   on:
     push:
       branches: [ main, develop ]
     pull_request:
       branches: [ main ]
   
   jobs:
     build:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v3
         - name: Set up JDK 17
           uses: actions/setup-java@v3
           with:
             java-version: '17'
         - name: Run tests
           run: ./gradlew test
         - name: Build release APK
           run: ./gradlew bundleRelease
         - name: Upload to artifacts
           uses: actions/upload-artifact@v3
           with:
             name: nocturne-android
             path: app/build/outputs/
   ```

2. Create `.github/workflows/android-deploy.yml`:
   ```yaml
   name: Deploy to Play Store
   
   on:
     push:
       tags:
         - 'v*'
   
   jobs:
     deploy:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v3
         - name: Set up JDK 17
           uses: actions/setup-java@v3
           with:
             java-version: '17'
         - name: Build release bundle
           run: ./gradlew bundleRelease
         - name: Deploy to Play Store
           uses: r0adkll/upload-google-play@v1
           with:
             serviceAccountJson: ${{ secrets.PLAY_STORE_SERVICE_ACCOUNT }}
             packageName: com.nocturne.android
             releaseFiles: app/build/outputs/bundle/release/app-release.aab
             track: internal
   ```

3. Output: Automated builds + deployments

**Checklist:**
- [ ] GitHub Actions workflows created
- [ ] Tests run automatically on push
- [ ] Release bundle builds successfully
- [ ] Play Store deployment configured (need credentials)
