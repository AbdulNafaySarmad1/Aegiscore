### Pakistan-Specific Statutory Deductions
```csharp
public class PayrollCalculator
{
    public PayslipData CalculatePayslip(Employee emp, int month, int year)
    {
        var basic = emp.CurrentSalary.BasicSalary;
        var earnings = new Dictionary<string, decimal>
        {
            { "Basic", basic },
            { "HRA", basic * 0.20m }, // House Rent Allowance
            { "Conveyance", 5000 }, // Standard conveyance
            { "Medical", 3000 } // Medical allowance
        };
        
        var grossSalary = earnings.Values.Sum();
        
        // Deductions per Pakistan statutory requirements
        var deductions = new Dictionary<string, decimal>();
        
        // EOBI (Employees Old-Age Benefits Insurance): 5% by employee
        deductions["EOBI"] = basic * 0.05m;
        
        // Income Tax per 2024 slabs (simplified)
        var taxableIncome = grossSalary - deductions["EOBI"];
        deductions["Income Tax"] = CalculateFederalIncomeTax(taxableIncome);
        
        // Provident Fund (optional, per contract): 5%
        if (emp.ProvidentFundEnabled)
            deductions["Provident Fund"] = basic * 0.05m;
        
        var totalDeductions = deductions.Values.Sum();
        var netSalary = grossSalary - totalDeductions;
        
        return new PayslipData 
        { 
            Earnings = earnings, 
            Deductions = deductions, 
            NetSalary = netSalary 
        };
    }
    
    private decimal CalculateFederalIncomeTax(decimal taxableIncome)
    {
        // 2024 Pakistan income tax slabs (FBR)
        if (taxableIncome <= 600000) return 0;
        if (taxableIncome <= 1200000) return (taxableIncome - 600000) * 0.05m;
        if (taxableIncome <= 2400000) return 30000 + (taxableIncome - 1200000) * 0.15m;
        return 210000 + (taxableIncome - 2400000) * 0.25m;
    }
}
```

### Payroll Workflow
1. Finance Head initiates payroll run for month
2. System calculates payslips for all active employees:
   - Fetch current salary structure
   - Apply statutory deductions (EOBI, income tax, provident fund)
   - Deduct unpaid leave (if any)
   - Generate payslip
3. Finance Head reviews total before locking
4. Once locked: generate bank transfer file (for batch payments)
5. Employee receives payslip (email + portal download)

### Bank Transfer Export

- Include: employee bank account, amount, reference
- One file per payment run

## Task 5 — Gratuity & Pension Calculation

### Gratuity (Pakistan-Specific)
```csharp
// For permanent employees only
public class GratuityCalculator
{
    public decimal Calculate(Employee emp, DateTime resignationDate)
    {
        var yearsOfService = (resignationDate - emp.DateOfJoining).TotalDays / 365.25;
        
        if (yearsOfService < 1) return 0; // Min 1 year service
        
        // Standard: (Final Salary / 30) * Years of Service
        var finalSalary = emp.CurrentSalary.BasicSalary + emp.CurrentSalary.HRA;
        var gratuity = (finalSalary / 30) * yearsOfService;
        
        return gratuity;
    }
}
```

### Pension (EOBI)
- EOBI automatically deducted from salary (5% employee + 5% employer)
- Employee entitled to pension at age 60 (or after 15 years service)
- System calculates and exports to EOBI annually

### Workflow
1. HR initiates appraisal cycle for academic year
2. HOD appraises faculty using configurable KPIs (top-down or 360-degree)
3. Overall score calculated as weighted average of KPIs
4. Appraisal results used for promotion/increment decisions
5. Data feeds into OBE framework (faculty workload contribution)
