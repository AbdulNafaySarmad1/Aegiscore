# S8 Accessibility Audit

- Keyboard navigation: all controls are native buttons or inputs with visible focus states.
- Screen readers: landmark labels, heading structure, input labels, and notification labels are present.
- Contrast: light and dark palettes meet WCAG AA for body text and primary controls.
- Responsive: layouts collapse below 900px and table rows stack below 540px without text overlap.
- Open issue count: 0 known issues before automated axe/browser verification.
