### STEP 9: Auto-Fix Failing Tests

**Task:**
For each failing test, implement the fix in the source code:

**Fix #1: OT Overtime Calculation**
```csharp
// BEFORE (broken):
public decimal CalculateOvertimePay(Employee emp)
{
    return emp.TotalHoursWorked * emp.HourlyRate; // Wrong!
}

// AFTER (fixed):
public PayrollBreakdown CalculateOvertimePay(Employee emp)
{
    const int regularHoursLimit = 60;
    
    var regularHours = Math.Min(emp.TotalHoursWorked, regularHoursLimit);
    var overtimeHours = emp.TotalHoursWorked - regularHours;
    
    var regularPay = regularHours * emp.HourlyRate;
    var overtimePay = overtimeHours * emp.HourlyRate * 1.5m; // 50% premium
    
    return new PayrollBreakdown
    {
        RegularHours = regularHours,
        OvertimeHours = overtimeHours,
        RegularPay = regularPay,
        OvertimePay = overtimePay,
        TotalPay = regularPay + overtimePay
    };
}
```

**Fix #2: CGPA with Incomplete Courses**
```csharp
// BEFORE (broken):
public decimal CalculateCGPA(Student student, List<Course> courses)
{
    var totalPoints = courses.Sum(c => c.GradePoints);
    return totalPoints / courses.Count;
}

// AFTER (fixed):
public decimal? CalculateCGPA(Student student, List<Course> courses)
{
    var completedCourses = courses.Where(c => c.Status != "Incomplete").ToList();
    
    if (completedCourses.Count == 0)
    {
        return null; // No completed courses = no CGPA
    }
    
    var totalPoints = completedCourses.Sum(c => c.GradePoints);
    return totalPoints / completedCourses.Count;
}
```

**Fix #3: HOD Cannot Approve Own Request**
```csharp
// BEFORE (broken):
public bool CanApprove(User approver, ApprovalRequest request)
{
    return approver.Role == "HOD" || approver.Role == "VC";
}

// AFTER (fixed):
public bool CanApprove(User approver, ApprovalRequest request)
{
    // Check role
    if (approver.Role != "HOD" && approver.Role != "VC")
        return false;
    
    // Check conflict of interest
    if (approver.UserId == request.RequestedBy)
        return false; // Cannot approve own request
    
    return true;
}
```
