# AegisCore — Sprint 3: Examination (Assessment Schemes → Marks → Grading → Transcripts)

## Role
You are a senior .NET 10 / C# 14 engineer building the examination and grading engine for AegisCore. This module handles assessment schemes, marks entry, automatic SGPA/CGPA calculation, result publication, and transcript generation.

---

## Task 1 — Assessment Scheme Builder

### Database Tables
```sql
CREATE TABLE assessment_schemes (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    course_id UUID NOT NULL REFERENCES courses(id),
    semester_id UUID NOT NULL REFERENCES semesters(id),
    exam_controller_id UUID NOT NULL REFERENCES users(id),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE assessment_components (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    scheme_id UUID NOT NULL REFERENCES assessment_schemes(id),
    component_type VARCHAR(50) NOT NULL, -- quiz | midterm | assignment | final | attendance | project
    weight_percentage INT NOT NULL,
    total_marks INT NOT NULL,
    passing_marks INT,
    is_mandatory BOOLEAN DEFAULT FALSE,
    order_index INT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
    -- CONSTRAINT: sum of weight_percentage across all components must == 100
);
```

### UI
- Exam Controller selects course → semester
- Table showing configurable components:
  - Component type (dropdown)
  - Weight % (numeric)
  - Total marks (numeric)
  - Passing marks (numeric, optional)
  - Is mandatory checkbox
  - Delete button
- Live validation: weight percentages must sum to 100
- Save assessment scheme

2. Exam Controller reviews: can approve or request clarification (reject)
3. If rejected: faculty re-enters and resubmits
4. If approved: marks locked, moves to grading calculation

## Task 4 — Grading Engine

### Database Tables
```sql
CREATE TABLE grade_scales (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    university_id UUID NOT NULL REFERENCES universities(id),
    name VARCHAR(100) NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE grades (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    grade_scale_id UUID NOT NULL REFERENCES grade_scales(id),
    letter_grade VARCHAR(2) NOT NULL, -- A, B, C, D, F
    gpa_points DECIMAL(3, 2) NOT NULL,
    percentage_from INT NOT NULL,
    percentage_to INT NOT NULL,
    description VARCHAR(200),
    UNIQUE(grade_scale_id, letter_grade)
);

CREATE TABLE course_grades (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    course_id UUID NOT NULL REFERENCES courses(id),
    student_id UUID NOT NULL REFERENCES users(id),
    total_marks_obtained DECIMAL(10, 2),
    percentage_obtained DECIMAL(5, 2),
    letter_grade VARCHAR(2),
    grade_points DECIMAL(3, 2),
    is_passing BOOLEAN,
    result_status VARCHAR(20) DEFAULT 'pending', -- pending | calculated | published
    calculated_at TIMESTAMPTZ,
    published_at TIMESTAMPTZ,
    UNIQUE(course_id, student_id)
);
```

### Grading Service
```csharp
public interface IGradingService
{
    Task CalculateCourseGradeAsync(Guid courseId, Guid studentId, CancellationToken ct = default);
    Task<SemesterGPA> CalculateSGPAAsync(Guid studentId, Guid semesterId, CancellationToken ct = default);
    Task<decimal> CalculateCGPAAsync(Guid studentId, CancellationToken ct = default);
    Task ApplyGracemarksAsync(Guid courseId, IEnumerable<GracemarkEntry> entries, Guid actorId, CancellationToken ct = default);
}

public class SemesterGPA
{
    public decimal Gpa { get; set; }
    public int TotalCredits { get; set; }
    public int CompletedCredits { get; set; }
    public List<CourseGrade> Grades { get; set; }
}
```

Calculation:
1. For each student in course: sum(component_marks) = total_obtained
2. Percentage = (total_obtained / total_marks) * 100
3. Map percentage to letter grade using `grades` lookup
4. GPA points = grade.gpa_points
5. SGPA (Semester GPA) = sum(grade_points * course_credits) / total_credits
6. CGPA (Cumulative GPA) = sum(all SGPAs * credit-weighted) / total credits

### Grace Marks
Policy config: `examination | grace_marks_max | 2`

Exam Controller can apply grace marks (max per policy):
- View all courses where average is near passing threshold
- Apply grace marks to specific students (logged in audit)
- Recalculate grades

## Task 5 — Automatic Result Calculation

### Scheduled Service
```csharp
public class ResultCalculationService : BackgroundService
{
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            var now = DateTime.UtcNow;
            var resultCalculationDate = await _academicCalendarService.GetResultCalculationDateAsync();
            
            if (now >= resultCalculationDate && !AlreadyCalculatedThisSemester())
            {
                await CalculateAllResultsAsync(stoppingToken);
            }
            
            await Task.Delay(TimeSpan.FromHours(1), stoppingToken);
        }
    }
}
```

On trigger:
1. Verify all marks moderation is approved
2. Calculate grades for all courses in semester
3. Calculate SGPA for all students
4. Generate grade reports
5. Flag at-risk students (GPA < 2.0 or failing too many courses)
6. Publish results (status=published in course_grades)

## Task 6 — Hall Ticket Generation

### Database Table
```sql
CREATE TABLE exam_registrations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    student_id UUID NOT NULL REFERENCES users(id),
    course_id UUID NOT NULL REFERENCES courses(id),
    exam_date DATE NOT NULL,
    exam_time TIME NOT NULL,
    exam_hall VARCHAR(100),
    seat_number INT,
    attendance_percentage DECIMAL(5, 2),
    is_attendance_eligible BOOLEAN, -- check: attendance >= policy config threshold
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE exam_schedules (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    course_id UUID NOT NULL REFERENCES courses(id),
    semester_id UUID NOT NULL REFERENCES semesters(id),
    exam_date DATE NOT NULL,
    exam_time TIME NOT NULL,
    duration_minutes INT NOT NULL DEFAULT 120,
    room_capacity INT NOT NULL,
    invigilator_count INT NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

### Hall Ticket Generation Workflow
1. Exam Controller schedules exams (date, time, room capacity, invigilators)
2. System checks eligibility per student:
   - Attendance >= threshold (default 75% from policy config)
   - Has not been withdrawn from course
   - Has not exceeded drop deadline
3. System allocates students to exam halls + seat numbers (auto)
4. Generate hall ticket (PDF) with:
   - Student name, roll number, CNIC
   - Course code, name, credits
   - Exam date, time, hall, seat number
   - QR code (anti-fraud, contains student hash)
5. Email hall ticket to student
6. Hall ticket downloadable from student portal

   - Sends results notification to students

## Task 8 — Transcript Generation

### Database Table
```sql
CREATE TABLE transcripts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    student_id UUID NOT NULL REFERENCES users(id),
    generated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    pdf_file_path TEXT NOT NULL,
    verification_hash VARCHAR(64), -- SHA-256 of PDF for anti-fraud
    is_official BOOLEAN DEFAULT FALSE,
    requested_by UUID REFERENCES users(id) -- NULL if system-generated
);
```

### Transcript Content
- Student name, ID, program, graduation date
- Semester-by-semester grades
  - Course code, name, credits, grade, GPA points
  - Semester GPA (SGPA)
- Cumulative GPA (CGPA)
- Total credits completed
- QR code for verification (links to anti-fraud server)
- Digital signature

### Generation Service
```csharp
public interface ITranscriptService

}
```

### Student-Initiated Transcript Requests
- Student portal: "Request Transcript"
- Dropdown: character certificate / bonafide / leaving certificate / academic transcript
- System creates request record
- Admin approves or rejects (optional for automated requests)
- Auto-generate and email PDF to student within 24 hours
