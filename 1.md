# PROMPT 1: Frontend/Backend Codebase Split
## Nocturne AegisCore Monolith → Microarchitecture

---

## OBJECTIVE

Split the Nocturne AegisCore monolithic codebase into:
1. **BACKEND** — Docker container (C# .NET 10 API only)
2. **FRONTEND** — Separate repository (React web app)
3. **MOBILE** — Separate repository (React Native + Kotlin + Swift)

Result: Clean architecture, independent deployments, separate version control.

---

## CURRENT STATE

```
AegisCore/
├─ src/
│  ├─ Nocturne.API/ (C# .NET 10 backend)
│  ├─ Nocturne.Web/ (React frontend)
│  ├─ Nocturne.Mobile/ (React Native)
│  ├─ Nocturne.Android/ (Kotlin)
│  └─ Nocturne.iOS/ (Swift) [TO DO]
```

**Problem:** Everything in one repo. Deployments coupled. Version management messy.

### STEP 4: Update API for CORS & Multi-Origin

**Task:**
Since frontend and backend are now separate repos (different deployment URLs), enable CORS:

1. In `Nocturne.API/Program.cs`, add:
   ```csharp
   var allowedOrigins = builder.Configuration
       .GetSection("AllowedOrigins")
       .Get<string[]>() ?? new[] { "http://localhost:3000" };
   
   builder.Services.AddCors(options =>
   {
       options.AddPolicy("AllowFrontend", policy =>
       {
           policy.WithOrigins(allowedOrigins)
               .AllowAnyMethod()
               .AllowAnyHeader()
               .AllowCredentials();
       });
   });
   
   app.UseCors("AllowFrontend");
   ```

2. Update `appsettings.json`:
   ```json
   {
     "AllowedOrigins": [
       "http://localhost:3000",
       "https://nocturne.university.edu.pk",
       "https://*.azurewebsites.net"
     ]
   }
   ```

3. Output: Backend API accepts requests from frontend (any URL)

**Checklist:**
- [ ] CORS middleware applied globally
- [ ] Frontend can call backend API without CORS errors
- [ ] Environment-specific origins configured

### STEP 5: Create Unified Dockerfile for Backend ONLY

**Task:**
1. Create `nocturne-backend/Dockerfile`:
   ```dockerfile
   # Multi-stage build for .NET 10 API
   FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
   
   WORKDIR /src
   
   # Copy solution files
   COPY ["Nocturne.sln", "./"]
   COPY ["src/", "src/"]
   
   # Restore dependencies
   RUN dotnet restore "Nocturne.sln"
   
   # Build API only (exclude Web, Mobile projects)
   RUN dotnet build "src/Nocturne.API/Nocturne.API.csproj" -c Release -o /app/build
   
   # Publish
   FROM build AS publish
   RUN dotnet publish "src/Nocturne.API/Nocturne.API.csproj" -c Release -o /app/publish
   
   # Runtime image
   FROM mcr.microsoft.com/dotnet/aspnet:8.0
   
   WORKDIR /app
   
   # Copy published files
   COPY --from=publish /app/publish .
   
   # Environment
   ENV ASPNETCORE_URLS=http://+:5000
   ENV ASPNETCORE_ENVIRONMENT=Production
   
   # Health check
   HEALTHCHECK --interval=30s --timeout=3s --start-period=40s --retries=3 \
       CMD curl -f http://localhost:5000/health || exit 1
   
   EXPOSE 5000
   
   ENTRYPOINT ["dotnet", "Nocturne.API.dll"]
   ```

2. Create `.dockerignore`:
   ```
   **/.git
   **/.gitignore
   **/node_modules
   **/dist
   **/build
   **/.vs
   **/.vscode
   **/bin
   **/obj
   **/Nocturne.Web/
   **/Nocturne.Mobile/
   **/Nocturne.Android/
   **/Nocturne.iOS/
   ```

3. Output: Optimized Docker image (backend only, ~500MB)

**Checklist:**
- [ ] Docker image builds: `docker build -t nocturne-api:1.0.0 .`
- [ ] Container starts: `docker run -p 5000:5000 nocturne-api:1.0.0`
- [ ] Health check endpoint responds: `curl http://localhost:5000/health`

### STEP 6: Update docker-compose for Multi-Container Setup

**Task:**
1. Create `nocturne-backend/docker-compose.yml`:
   ```yaml
   version: '3.8'
   
   services:
     api:
       build:
         context: .
         dockerfile: Dockerfile
       ports:
         - "5000:5000"
       environment:
         - ASPNETCORE_ENVIRONMENT=Development
         - ConnectionStrings__DefaultConnection=Host=postgres;Port=5432;Database=nocturne;Username=postgres;Password=postgres
         - Redis__Host=redis
         - Redis__Port=6379
       depends_on:
         - postgres
         - redis
       networks:
         - nocturne-net
   
     postgres:
       image: postgres:15-alpine
       environment:
         - POSTGRES_DB=nocturne
         - POSTGRES_USER=postgres
         - POSTGRES_PASSWORD=postgres
       volumes:
         - postgres-data:/var/lib/postgresql/data
       ports:
         - "5432:5432"
       networks:
         - nocturne-net
   
     redis:
       image: redis:7-alpine
       ports:
         - "6379:6379"
       networks:
         - nocturne-net
   
   volumes:
     postgres-data:
   
   networks:
     nocturne-net:
   ```

2. Output: Full local dev stack (API + PostgreSQL + Redis)

**Checklist:**
- [ ] Stack starts: `docker-compose up`
- [ ] API accessible at http://localhost:5000
- [ ] PostgreSQL accessible at localhost:5432
- [ ] Redis accessible at localhost:6379
